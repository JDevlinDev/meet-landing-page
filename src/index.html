Frontend Mentor

Newbie FEM Starter Pack

A newbie-friendly, BEM-inspired project template with zero-config bundling and optimization, and one-command deployment to GitHub Pages. Use it to build modular, scalable, and maintainable Frontend Mentor projects you'll want to keep building on. The template is built on the following tools:

  • Sass Programmable, reusable styles
  • BEM Component-based CSS conventions
  • Parcel Bundling and optimization
  • Prettier Opinionated code formatting
  • GitHub Pages Free hosting, deployed in one command
